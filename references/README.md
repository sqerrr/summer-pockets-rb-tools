# Локальные референсные корпуса

## CLANNAD

Существует полный русский патч «Энтузиасты Team» для Steam-версии. После установки на легальную копию текст можно попытаться извлечь локально инструментами, поддерживающими RealLive, либо адаптером к конкретной версии.

## Rewrite+

Русский патч также существует. Rewrite+ работает на SiglusEngine; для извлечения и обратной упаковки применяются специализированные инструменты Siglus, но точный путь зависит от версии игры и патча.

## В этом репозитории

Создайте локально:

```text
references/local/clannad/
references/local/rewrite/
```

Не коммитьте содержимое. Добавьте локальный `manifest.yaml`:

```yaml
game: CLANNAD
source: legally-owned-game-with-russian-patch
purpose: style-reference-only
text_path: extracted/
```

## Использование агентом

Агент может:

- искать примеры сходного регистра;
- считать среднюю длину реплик;
- анализировать пунктуацию;
- сравнивать способы передачи бытового юмора.

Агент не должен:

- выдавать большие выдержки;
- копировать чужую сцену;
- смешивать корпус с утверждённой памятью Summer Pockets;
- считать решения старого перевода автоматически правильными.
