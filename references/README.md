# Локальные референсные корпуса

Полные сторонние тексты и отобранные фрагменты находятся только здесь и не
коммитятся:

```text
references/local/<corpus>/manifest.yaml
references/local/<corpus>/extracted/...
references/local/<corpus>/fragments.jsonl
```

`manifest.yaml` описывает происхождение и доступные языки корпуса.
`fragments.jsonl` содержит только вручную отобранные цельные фрагменты сцен по
контракту `schemas/reference-fragment.schema.json`.

## Роли инструментов

- `vn-reference-curator` читает сцену вокруг кандидата, оформляет фрагмент и
  назначает `raw`, `usable`, `gold` или `rejected`;
- `vn-reference-retriever` сначала анализирует текущую сцену Summer Pockets, а
  затем при необходимости выбирает не более 1–3 подходящих фрагментов;
- статистика и grep могут сузить поиск, но не доказывают релевантность.

## Доступные корпуса

- CLANNAD: локально извлечён русский патч; без парного исходника его фрагменты
  оценивают только русский текст и не получают `gold`.
- Rewrite+: может быть подключён тем же способом после извлечения и проверки.
- Будущие корпуса с японским, английским, китайским и русским текстом могут
  хранить все доступные варианты в `lines[].source`.

Подробная политика — `docs/reference-corpus-policy.md`. Готовые формулировки не
копируются, полный корпус не смешивается с памятью Summer Pockets.
