# Translation Policy Template

Customize this file before real translation.

## Source Priority

Define the authoritative source language and the role of aligned official or
fan reference slots. References are evidence, not wording templates.

## Fidelity

Preserve concrete entities, comparison direction, lists, numbers, negation,
modality, causality, ambiguity, interruptions, and intentional repetition.

## Target Style

Define register, dialogue punctuation, names, honorifics, terminology,
typography, and any platform glyph limits.

## Uncertainty

Use a provisional translation and a tracked question. Do not silently turn a
local guess into project-wide policy.

## Protected Material

Engine tokens, placeholders, variables, tags, choices, and control codes are
not translatable. The adapter and QA configuration define their exact contract.
