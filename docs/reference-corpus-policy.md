# Политика использования внешних русских переводов

## Назначение

Русские переводы CLANNAD, Rewrite и других игр Key могут использоваться как локальный стилистический корпус.

Они не являются:

- источником смысла Summer Pockets;
- обязательной нормой;
- материалом для копирования готовых сцен;
- заменой персонажным карточкам текущей игры.

## Что анализировать

- разговорность и длину реплик;
- оформление внутренних монологов;
- пунктуацию;
- передачу японских реалий;
- способы адаптации комедийных сцен;
- устойчивость имён и обращений;
- типичные проблемы, которых следует избегать.

## Что запрещено

- коммитить полный чужой перевод;
- отправлять весь корпус в публичный облачный индекс без разрешения;
- копировать длинные фрагменты;
- смешивать чужие строки с translation memory текущего проекта;
- обучать на корпусе модель или публиковать производный датасет без проверки прав.

## Практическая схема

1. Пользователь устанавливает легально полученную игру и русификатор.
2. Текст извлекается локально в `references/local/<game>/`.
3. Каталог находится в `.gitignore`.
4. Агент строит только локальный индекс и статистику.
5. В проект попадают не полные цитаты, а утверждённые стилевые выводы.

Пример стилевого вывода:

```yaml
register: modern-colloquial
narration: concise-first-person
honorific_policy: mostly-localized
notes:
  - "Не злоупотреблять японскими междометиями"
  - "Комедийный ритм важнее дословного порядка"
```

## Короткие примеры

Небольшие фрагменты можно хранить только локально как примеры выбора тона. В коммитах предпочтительнее ссылаться на локальный ID корпуса и записывать собственный вывод, а не копировать текст.
