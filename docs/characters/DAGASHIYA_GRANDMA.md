# Бабуля из лавки сладостей

## Безопасное описание

Пожилая хозяйка лавки сладостей.

## Базовая письменная речевая манера

- Реплики короткие, старомодные и невозмутимые.
- Западнояпонский говор передаётся по DEC-0028 без русской географической привязки.
- Юмор произносится сухо, без пояснения шутки и без добавленного эмоционального нажима.

## Не использовать

- Русский деревенский диалект, оканье и фонетические редукции.
- Современный молодёжный сленг.
- Многословные пояснения вместо короткой исходной реплики.
