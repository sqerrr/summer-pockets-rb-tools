# Мики

Карточка построена по индексу: 3032 реплики в 140 сценах.

## Безопасное описание

Не заполняется.

## Проверка внешнего утверждения об «уставной речи»

Заявлено, что она говорит «по регламенту». **В той форме, в какой это обычно
делается в японском, не подтвердилось:** 「であります」 — 0 вхождений, 「であ」 —
4. Вежливых форм у неё практически нет: です 47 и ます 30 на 3032 реплики (1.5% и
1.0%).

Подтвердилось другое и вполне отчётливо: **мужская твёрдая простая форма,
регистр командира, а не подчинённого.**

## Базовая письменная речевая манера

- Связки и частицы: 「~だな」 — 121, 「~ぞ」 в конце реплики — 90, 「~だが」 — 86,
  「そうか」 — 54. Вместе это ровный, рубленый утвердительный слог.
- Побуждение через 「~てくれ」, а не через просьбу: 「夏休みを楽しんでくれ」.
- Прямой запрет без смягчения: 「脱ぐな、ここは公共の場だ」.
- Местоимение первого лица 私 — 327 вхождений (кандзи, число ориентировочное),
  при этом весь окружающий регистр мужской. Это сочетание и есть её особенность:
  女性の私 плюс 男性的常体. По-русски местоимение регистра не несёт, поэтому
  твёрдость обязана держаться на синтаксисе — короткие утверждения, отсутствие
  смягчающих частиц, повелительные без «пожалуйста».

## Обращения — самый чистый маркер

**Она обращается по голому имени, без именного суффикса, вообще.**

- 「鷹原」 — 234 вхождения. 「鷹原さん」 — **0**.
- В выборке так же: 「良一」, 「天善」, 「しろは」 — без суффикса.

Ноль при 234 — это не статистический перевес, а правило. По-русски: только имя,
никогда не «господин», не уменьшительное, не по фамилии с отчеством-эквивалентом.

## Поведение в разных состояниях

### Нейтральное

Короткое утверждение на 「~だ」/「~だな」, при необходимости с уступкой 「~だが」.

### Смущение

Единичное 「そ、そうか？」 в выборке; частотного признака нет. Раздел неполон
намеренно.

### Раздражение

Не заполняется: отдельного формального признака не выделено.

### Стресс

Не заполняется.

### Близкий разговор

Не заполняется.

## Не использовать

- Именные суффиксы и вежливые обращения: 「鷹原さん」 — 0 из 234.
- Вежливые формы: 2.5% суммарно.
- «Женственный» смягчённый синтаксис: у неё わ-регистра нет, в отличие от Ао.
- Военно-канцелярский штамп как передачу «уставности»: 「であります」 в тексте
  отсутствует, и русский аналог был бы придуман, а не переведён.
- 「えっへん」 как присловье: 3 вхождения в одной сцене, это разовая шутка.

## Ограничение метода

Числа по кане (だな, ぞ」, だが, そうか, です, ます, であります, えっへん) и по
смешанным формам (鷹原さん) японские по построению. Число по 私 ориентировочное:
запрос по чистым кандзи захватывает китайский слот.
