# Политика переводческих примеров

## Зачем нужны примеры

Абстрактная инструкция «говорит сдержанно» слабее нескольких утверждённых реплик, показывающих реальный русский голос. Однако большое количество случайных примеров перегружает контекст и закрепляет ошибки.

## Приоритет примеров

1. Утверждённые реплики текущего перевода Summer Pockets.
2. Несколько вручную отобранных вариантов из уже проверенных сцен того же персонажа.
3. Официальный английский перевод только как справочная трактовка.
4. Локальные корпуса CLANNAD/Rewrite только для общего русского регистра.

## Примеры персонажа

Для каждой основной карточки постепенно накопить 8–20 примеров, покрывающих разные функции:

- нейтральный ответ;
- комическая реакция;
- смущение;
- раздражение;
- серьёзный разговор;
- обращение к ключевому персонажу;
- внутренне противоречивая или недосказанная реплика.

Не добавлять пять почти одинаковых реплик только потому, что они звучат удачно.

## Что хранить

В карточке персонажа хранить:

- `segment_id`;
- функцию примера;
- короткий комментарий о приёме;
- при необходимости утверждённую формулировку.

Полный исходный контекст всегда можно получить по `segment_id` из индекса.

## Когда пример становится утверждённым

Пример можно использовать как опорный, если:

- смысл проверен по японскому;
- сцена имеет статус не ниже `reviewed`;
- реплика не содержит временного термина;
- голос не был отмечен `needs_voice_review`;
- пример не раскрывает будущие сведения для текущей точки.

## Внешние примеры CLANNAD/Rewrite

Они используются для ответа на вопросы вида:

- насколько разговорным может быть повествование Key по-русски;
- как в существующих переводах оформлены паузы;
- какова средняя плотность междометий;
- насколько свободно перестраиваются шутки.

Они не используются как few-shot примеры конкретного персонажа Summer Pockets и не должны автоматически вставляться в каждый запрос.

## Этап калибровки

После подключения локальных корпусов агент создаёт `docs/style-profile.yaml` с собственными выводами. Пользователь проверяет профиль. Только утверждённый профиль становится частью общего контекста.
