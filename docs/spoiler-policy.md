# Политика защиты от спойлеров

## Цель

Пользователь должен иметь возможность проходить игру впервые, даже если агент использует будущий сценарий для сохранения намёков и повторов.

## Разделение знаний

### Безопасная область

`docs/` содержит:

- уже раскрытые факты;
- текущие наблюдаемые черты;
- безопасные переводческие правила;
- резюме пройденных сцен.

### Закрытая область

`private/` может содержать:

- истинные мотивы;
- будущие раскрытия;
- связи между маршрутами;
- объяснение намёков;
- причины намеренной двусмысленности.

## Контракт закрытого ограничения

```json
{
  "id": "HIDDEN-0001",
  "segment_ids": ["COMMON_001_SC01_0007"],
  "private_reason": "Полное спойлерное объяснение.",
  "safe_rules": [
    "Не уточнять субъект.",
    "Сохранить нейтральное обозначение явления."
  ],
  "reveal_after": "ROUTE_X_SC99",
  "status": "active"
}
```

`private_reason` запрещено включать в пользовательский контекст, отчёт, имя файла и сообщение коммита.

## Допустимый видимый вывод

- «Сохранить двусмысленность».
- «Не конкретизировать адресата».
- «Формулировка может иметь дальнейшее значение; оставить нейтральной».
- «Термин пока временный».

## Недопустимый вывод

- описание будущего поворота;
- указание настоящей личности;
- объяснение, почему событие произойдёт;
- название будущей ветки, если оно само является спойлером;
- комментарий «позже выяснится, что…».

## Фильтрация

Из закрытых constraints `tools/vnctl.py context` выводит только `safe_rules`;
остальной безопасный контекст сцены, решения и глоссарий остаются в пакете.

Любой новый инструмент контекста обязан иметь тест, доказывающий, что поле `private_reason` отсутствует в выходе.

## Постепенное раскрытие

После прохождения сцены разрешено переносить ставшие известными факты из `private/` в безопасные резюме. Перенос выполняет `vn-knowledge`.
