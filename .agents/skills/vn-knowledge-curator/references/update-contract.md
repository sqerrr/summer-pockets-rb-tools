# Knowledge update contract

```yaml
glossary_updates: []
character_updates: []
relationship_updates: []
decision_updates: []
scene_summary_update: null
private_constraint_updates: []
unresolved: []
```

Each update must include:

- target file or entity;
- proposed text/value;
- status;
- evidence segment IDs;
- safe reason;
- whether user approval is required.

Prefer editing a specific section over replacing an entire Markdown file.
