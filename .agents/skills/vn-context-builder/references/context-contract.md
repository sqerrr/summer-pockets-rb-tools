# Context package contract

Required sections:

1. Task and scene ID
2. Applicable global rules
3. Current progress boundary
4. Scene participants
5. Character voice notes
6. Relevant glossary entries
7. Approved linked decisions
8. Safe hidden constraints
9. Previous-scene safe summary
10. Immediate previous/next segments
11. Full current scene

The package must not contain keys or text labelled `private_reason`.

Recommended total size: 10k–80k tokens. Larger packages require a reason.
