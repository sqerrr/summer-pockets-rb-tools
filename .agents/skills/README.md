# Репозиторные Agent Skills

Эти skills расположены в `.agents/skills`, чтобы Codex мог обнаруживать их на уровне репозитория. Каждый навык соответствует открытому формату Agent Skills и содержит обязательный `SKILL.md`.

Любая операция сначала проходит через критический управляющий слой:

1. `vn-project-orchestrator`
2. `vn-project-gatekeeper`
3. Один из специализированных skills, разрешённый текущей фазой:
   `vn-bootstrap`, `vn-context-builder`, `vn-scene-translator`,
   `vn-scene-reviewer`, `vn-knowledge-curator` или `vn-engine-siglus`.

Отдельно стоит `vn-engine-siglus` — движковый слой. Он не участвует в переводческом цикле и вызывается тогда, когда нужно распаковать или собрать `Scene.pck`, изменить шрифты либо таблицу кодирования, а также проверить сборку на запущенной игре.

Оркестратор не заменяет специализированные навыки и не выполняет их предметную
работу. Навыки намеренно узкие. Не объединять их в один монолитный prompt без
доказанной пользы.
