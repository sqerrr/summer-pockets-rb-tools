# Исторический шаблон первой задачи

Этот файл описывает начальный bootstrap и больше не является текущим заданием.
Фактический следующий блок берётся из `python tools/vnctl.py resume`; активный
профиль и источники определены в `config/project.yaml`.

Работай в существующем Git-репозитории перевода визуальной новеллы.

## Исходное состояние

- Исходные сценарные файлы уже получены.
- Существующий код смог распарсить сценарий.
- Предположительно код умеет собирать сценарий обратно, но это ещё надо подтвердить.
- Перевод, каталог, глоссарий и карточки персонажей ещё не созданы.
- Пользователь хочет пройти игру впервые и не должен получать будущие спойлеры.

## Обязательные инструкции

1. Прочитай `AGENTS.md`.
2. Активируй skill `vn-bootstrap` и следуй ему.
3. Изучи существующие парсер и сборщик. Не заменяй их без доказанной необходимости.
4. До перевода реального текста выполни round-trip без изменения текста.
5. Опиши команды и результат в `docs/project/parser-audit.md`.
6. Создай тонкий адаптер к модели данных из `docs/data-model.md`.
7. Каталогизируй сценарий:
   - файлы;
   - маршруты, если их можно определить без спойлерных имён;
   - логические сцены;
   - реплики и повествование;
   - говорящих;
   - выборы, переходы и технические команды.
8. Присвой устойчивые и нейтральные ID.
9. Создай нормализованные JSONL в `translation/segments/` и `translation/scenes.jsonl`.
10. Запусти:

```bash
python tools/vnctl.py validate
python tools/vnctl.py index
python tools/vnctl.py stats
```

11. Выбери одну небольшую пилотную сцену, удобную для игрового smoke test.
12. Для пилота последовательно используй:
   - `vn-context-builder`;
   - `vn-scene-translator`;
   - `vn-scene-reviewer`.
13. Собери сцену в игру и проверь запуск.
14. Только после успешного пилота переходи к очереди сцен через
    `batch-translate`, сохраняя и проверяя каждую сцену отдельно.
15. Предоставь короткий безопасный отчёт:
   - что найдено;
   - какие команды работают;
   - какие файлы созданы;
   - результат round-trip;
   - результат пилотной сборки;
   - технические блокеры;
   - какие решения пока требуют пользователя.

## Защита от спойлеров

Не выводи будущие события, истинные мотивы и сюжетные связи. Если полный сценарий показывает, что раннюю фразу надо сохранить особым образом, создай запись в `private/constraints.jsonl`, а пользователю сообщи только безопасное правило.

## Критерий завершения первой задачи

Первая задача завершена, когда:

- round-trip подтверждён или точно локализован блокер;
- сценарий каталогизирован хотя бы для пилотного участка;
- ID устойчивы;
- индекс строится;
- одна сцена переведена, проверена и собрана;
- пользователь не получил спойлеров;
- все изменения зафиксированы понятными Git-коммитами.
